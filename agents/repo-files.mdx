## Committed

| File | What it's for |
| --- | --- |
| `AGENTS.md`, `CLAUDE.md` | A short FireWeave block telling agents when its instructions apply. |
| `.fireweave/project.json` | Binds the repository to your FireWeave project. |
| `.fireweave/agent-instructions.md`, `.fireweave/instructions/` | The full instructions an agent reads when FireWeave is on. |
| `.fireweave/hooks/` | The scripts your agents' hooks run: the on/off check and the stop check. |
| `.claude/settings.json`, `.cursor/hooks.json` | FireWeave's hook entries, added beside your team's. Other agents get their own hook file. |
| `.fireweave/stamps.ts` | One line per change, so each change is visible in git. |
| `src/fireweave/start.ts`, `control-points.ts` | The SDK's start call and your control points' local values, per app. |

The exact names depend on your agents and languages. FireWeave stores feature records itself, so there's no manifest file to edit.

## On your machine only

| File | What it's for |
| --- | --- |
| `.fireweave/local.json` | Your sign-in profile and your [instructions switch](/agents/instructions-switch). |
| `.fireweave/.cache/` | A local copy of what FireWeave knows about this repository. |

`.fireweave/.gitignore` keeps these out of git.

<Warning>
Hook scripts run as shell commands on every teammate's machine once merged. Review them in the setup pull request like any other code.
</Warning>
