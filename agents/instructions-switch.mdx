---
title: "Turn Fireweave's instructions on or off"
description: "Switch Fireweave's agent instructions off for your own clone, or require them for everyone on a project."
---

Fireweave's instructions are committed to your repository, but you can switch them off for your own clone. Your teammates, CI and the pull request check aren't affected.

```bash
fw agents off      # Fireweave stops guiding coding agents in this repo, on this machine
fw agents on       # turn it back on
fw agents status   # which state applies, and why
```

The change takes effect at your agent's next prompt and lasts on every branch until you switch it back. Run these yourself in a terminal: Fireweave's plugin stops an agent from running `fw agents on` or `off`.

## What off changes

| | When you switch off |
| --- | --- |
| Your coding agent in this clone | Ignores Fireweave's instructions and writes no control points |
| The stop check in this clone | Doesn't run |
| The readiness check on your pull request | Still runs |
| Teammates' clones | Unaffected |
| CI | Unaffected |

The switch lives in `.fireweave/local.json`, which git ignores.

## Require Fireweave for everyone

An Owner or Admin can turn on **Require Fireweave for every coding agent** in the project's **Settings → Repositories**. Saving opens a pull request that records the setting in `.fireweave/project.json`.

Once it's merged:

- Fireweave's instructions apply to everyone who works on the repository, set up or not.
- Coding agents make no changes until the person signs in with `fw login`. Questions and infra-only tasks still go ahead.
- `fw agents off` is refused:

```text
This project requires Fireweave for every coding agent; an Owner or Admin can change that in Project settings.
```

## Check the state

`fw agents status` prints one of these:

| State | Meaning |
| --- | --- |
| `on` | Fireweave's instructions apply. |
| `off` | You switched it off, or Fireweave isn't set up on this machine. |
| `ask` | You set this clone up but you're signed out. The agent asks you once to sign in or skip. |
| `sign-in` | The project requires Fireweave and you're signed out. Changes wait until you sign in. |

`fw status` and `fw doctor` print the same line.
