---
title: "HTTP API"
description: "Fireweave's two HTTP planes: the runtime routes your SDK calls, and the management routes for projects and environments."
---

Fireweave has two HTTP planes. Each takes its own kind of key, and a key for one never opens the other.

| Plane | Who calls it | Key |
| --- | --- | --- |
| Runtime | Your app, through an SDK | Server key, or a browser key in web apps |
| Management | Scripts, CI and [Terraform](/infrastructure/terraform/overview) | Org API key (`fw_org_…`) with the **Management** scope |

Send the key as `Authorization: Bearer <key>`. The production server is `https://app-server.fireweave.ai`.

## Runtime plane

Use an SDK rather than calling these yourself. They accept requests from any browser origin.

| Method | Path | Does |
| --- | --- | --- |
| `POST` | `/v1/control-points/evaluate` | Evaluate control points |
| `POST` | `/v1/capture` | Record exposures and events |
| `POST` | `/v1/targets/register` | Register a user or device for targeting |

## Management plane

The organization always comes from the key, never from the path.

| Method | Path | Does |
| --- | --- | --- |
| `GET` | `/v1/whoami` | Who the key belongs to: `userId`, `orgId`, `scope` |
| `GET` `POST` | `/v1/projects` | List or create projects |
| `GET` `PATCH` `DELETE` | `/v1/projects/{projectId}` | Read, update or delete a project |
| `GET` `POST` | `/v1/projects/{projectId}/environments` | List or create environments |
| `GET` `PATCH` `DELETE` | `/v1/projects/{projectId}/environments/{envId}` | Read, update or delete an environment |
| `GET` | `/v1/projects/{projectId}/control-points` | Control points that merges have registered |
| `GET` | `/v1/projects/{projectId}/control-points/graph` | The same, with recorded dependency edges |

```bash
curl https://app-server.fireweave.ai/v1/projects \
  -H "Authorization: Bearer $FW_ORG_API_KEY"
```

A **CI read** key reads only what [`fw sync`](/cli/ci) needs, plus `/v1/whoami`. It can't manage projects or environments.

## Errors

```json
{ "error": { "code": "NOT_FOUND", "message": "Project not found" } }
```

| Status | When |
| --- | --- |
| `401` | Missing or invalid key |
| `403` | The key's scope, or the role of the person who created it, doesn't allow the call |
| `404` | Unknown id, or an id in another organization |
| `409` | A project or environment slug that already exists |

Routes not listed here are not part of the public contract and may change.
