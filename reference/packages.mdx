`fireweave-sdk` is **2.3.0**. These leftover artifacts remain at **0.1.0** and are not the 2.3.0 SDK:

- `ai.fireweave:fireweave-openfeature` **0.1.0**
- `ai.fireweave:fireweave-adapter-posthog` **0.1.0**
- `ai.fireweave:fireweave-testing` **0.1.0**

Do not imply a uniform 2.3.0 line across every `ai.fireweave:*` coordinate.

### Swift

A Swift package exists in-tree at `sdks/swift/Package.swift` (iOS 16+, macOS 13+, zero dependencies, tag `swift/v2.2.0`). `Package.swift` is not at the repository root, so SwiftPM cannot resolve it from the repository URL. It is **not installable**. There is no Swift SDK page.

Node, Python core, Web, Go, and Java `fireweave-sdk` have zero runtime dependencies. Rust has exactly three: `ureq`, `serde`, `serde_json`.

See [Compatibility](/sdks/compatibility) for the adapter and type matrix.

## Env vars and config

**No SDK reads environment variables.** Credentials are explicit init options in every language.

| Name | Who reads it |
| --- | --- |
| `FW_API_URL` | **Nobody in the SDK.** Your app may read it and pass `apiUrl` / `api_url` / `APIURL`. |
| `FW_PROJECT_API_KEY` | **Nobody in the SDK.** Your app may read it and pass `apiKey` / `api_key` / `APIKey`. |
| `FW_DEPRECATION_WARNINGS` | **Nothing.** Removed. The `flags` alias is silent at runtime (Python emits one `DeprecationWarning` on first access). |

Timeouts: request **3000 ms**, shutdown **10000 ms**. Host allowlists and https rules: [Configuration](/production/configuration).

## Errors

15 kinds. Evaluation never throws. Full table: [Errors](/production/errors).

Node/Web: `FireweaveError`. Python: per-kind classes + `ErrorKind`. Go: `fireweave.Error`. Java: `ErrorKind` + `FireweaveException`. Rust: `FireweaveError`.

## Language gates

| API | Node | Python | Go | Java | Web | Rust |
| --- | --- | --- | --- | --- | --- | --- |
| Entry point | `initFireweave` | `init_fireweave` | `fireweave.Init` | `Fireweave.init` | `initFireweave` | `init_fireweave` |
| Product namespace | `controlPoints` | `control_points` | `ControlPoints()` | `controlPoints()` | `controlPoints` (sync) | `control_points` |
| Deprecated alias | `flags` (silent) | `flags` (one warning) | `Flags()` (silent) | `flags()` (silent) | `flags` (silent) | `flags()` (silent) |
| Register target | `client.registerTarget` | `client.register_target` | `client.RegisterTarget` | `client.registerTarget` | `registerTarget` + `identify` | `client.register_target` |

| Env auto-read | **no** | **no** | **no** | **no** | **no** | **no** |

The `flags` alias shares identity with `controlPoints` and is not the documented name.

See [HTTP API](/reference/http-api). The [test server](/testing) implements evaluate and `/health` — **not** `/v1/targets/register`.

## Runtime compatibility notes

- **Node** is ESM, portable across Node / Bun / Deno. Deno import: `npm:@fireweaveai/server-sdk`.
- **Web** targets browsers only. Suite runs on Bun + happy-dom. No server entry point.
- **Go** import and `go get` must include `/v2`.
- CI “latest” / “stable” / “canary” cells **float**. Document minimums from manifests.
- Swift is in-tree and not distributable. There is no Android, .NET, PHP, or Ruby package under `sdks/`.
