One line per term. The web app, the CLI and these docs use the same words.

## Organization and access

Roles and keys: [Team and security](/connect/team-and-security), [Keys](/connect/keys).

| Term | Meaning |
| --- | --- |
| **Project** | What your organization ships through Fireweave: its repositories, environments, settings, rollouts and keys. |
| **Environment** | One stage your project ships through, such as `staging` or `production`. |
| **Environment branch** | The branch tied to an environment. Merging into it registers a rollout. |
| **App (surface)** | One deployable app in one SDK language where control points live. |
| **Control point** | A named decision in your code, read through the SDK, that Fireweave can change without a deploy. |
| **Manifest** | The record of one feature's change: its control point, where it is wrapped and the metrics that watch it. |
| **Rollout** | The plan for moving one change out in one environment. |
| **Stage** | One step of a ramp: a percentage of traffic, then a hold. |
| **Hold (soak)** | The wait after a stage, while metrics are watched and checks are called. |
| **Guardrail** | A metric with a limit, and what happens on breach: **Block**, **Alert** or **Log**. |
| **Promotion check** | Your own HTTP endpoint that answers whether a stage may move on. |
| **Release safety** | Each pull request's latest risk reading, per project and per organization. |
| **Readiness check** | The **Fireweave — rollout readiness** check Fireweave reports on each pull request. |
| **Stable** | A control point whose rollout reached 100% and finished its stability soak. |
| **Cleanup** | A later change that removes the old code path of a stable control point. |
| **Server key** | The key a server app reads from `FIREWEAVE_KEY`. Keep it secret. |
| **Browser key** | The browser-safe key a web app reads from `FIREWEAVE_BROWSER_KEY`. It can only read control points and send events. |
