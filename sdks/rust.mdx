description: "Install the Fireweave Rust crate, start it in one line and read control points."
---

The Rust SDK is the `fireweave` crate. Its `fireweave::start` module is the [start profile](/sdks/start-profile): one call in `main`, then reads from anywhere.

<Steps>
  <Step title="Install">
    ```bash
    cargo add fireweave@3.0.0
    ```
  </Step>
  <Step title="Declare your control points">
    ```rust src/fireweave_control_points.rs
    use fireweave::start::{define_control_points, LocalControlPoint, LocalControlPoints};

    // Every control point the app reads, with the value served in local mode.
    pub fn control_points() -> LocalControlPoints {
        define_control_points([("new-checkout", LocalControlPoint::local(true))])
    }
    ```
  </Step>
  <Step title="Start once in main">
    ```rust src/main.rs
    use fireweave::start::StartOptions;

    fireweave::start::start(StartOptions {
        control_points: control_points(),
        ..Default::default()
    })?;
    ```
  </Step>
  <Step title="Read a control point">
    ```rust
    use fireweave::EvaluationContext;

    let ctx = EvaluationContext::new().with_targeting_key(&user.id);
    // @fireweave-controlpoint new-checkout
    if fireweave::start::control_points().get_boolean_value("new-checkout", false, Some(&ctx)) {
        // new path
    }
    ```
    Reads never panic or fail. If start failed, they return your default.
  </Step>
</Steps>

<Warning>
  In remote mode each read is one blocking request. Inside an async runtime, read from `spawn_blocking` (or `web::block`).
</Warning>

## Configuration

| Variable | Value |
| --- | --- |
| `FIREWEAVE_KEY` | Your project key (`project-api-key_…`). Set it in every deployed environment. |
| `FIREWEAVE_ENV`, then `APP_ENV` | `development`, `dev`, `local` or `test` with no key runs local. |
| `FIREWEAVE_URL` | Optional. Overrides the default endpoint. |

With no key outside a development environment, `start` returns a configuration error naming `FIREWEAVE_KEY`.

## Identify users

At sign-in, register the facts your targeting matches on:

```rust
if let Err(e) = fireweave::start::identify(&user.id, [("plan", "pro")]) {
    eprintln!("fireweave identify failed: {e}");
}
```

## Status and shutdown

- `fireweave::start::status()` reports the mode and why, the channel, endpoint and key source. It never contains the key.
- `fireweave::start::shutdown()` stops the client.

<Note>
  To configure the client yourself with no environment reads, use `fireweave::init_fireweave(InitOptions::remote(key, url))`.
</Note>
