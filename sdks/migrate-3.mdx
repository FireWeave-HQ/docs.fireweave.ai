3.0 makes every public name say **control point**, removes the 2.x aliases, and adds the start profile. Most upgrades are renames.

## Renames

| 2.x | 3.0 |
| --- | --- |
| `client.flags` | `client.controlPoints` (Python, Rust `control_points`; Go `ControlPoints()`) |
| Error kind `FlagNotFound` | `ControlPointNotFound` (Python `ControlPointNotFoundError`; Go `KindControlPointNotFound`, `ErrControlPointNotFound`; Dart, Swift `.controlPointNotFound`) |
| Decision `flagKey` | `controlPointKey` (Node, Web, Go, Java) |
| Decision `flagMetadata` | `controlPointMetadata` (Python, Rust `control_point_metadata`; Dart, Swift) |
| Metadata `fireweave.flagVersion` | `fireweave.controlPointVersion` |
| Metadata `fireweave.vendorFlagId` | `fireweave.vendorControlPointId` |
| Python `get_integer_value` | `get_number_value` |
| Go `github.com/FireWeave-HQ/fireweave-sdk/sdks/go/v2` | `…/sdks/go/v3` |

The `errorCode` value for a missing control point is still `FLAG_NOT_FOUND`.

## Environment variables

The start profile reads only `FIREWEAVE_*` names. A deploy that sets only an old name now fails at start. The values don't change.

| 2.x | 3.0 |
| --- | --- |
| `FW_PROJECT_API_KEY` | `FIREWEAVE_KEY` |
| `FW_API_URL` | `FIREWEAVE_URL` (optional) |

`initFireweave` (and each language's equivalent) still reads no environment: you pass the key and URL yourself, as in 2.x.

## Move to the start profile

You can keep calling `initFireweave`. The start profile replaces it with one call and a control-points file.

<CodeGroup>

```ts Before (2.x)
import { initFireweave } from '@fireweaveai/server-sdk';

const fireweave = await initFireweave({
  mode: 'remote',
  apiUrl: process.env.FW_API_URL!,
  apiKey: process.env.FW_PROJECT_API_KEY!,
});
await fireweave.controlPoints.getBooleanValue('new-checkout', false, { targetingKey: user.id });
```

```ts After (3.0)
import { start, fw, defineControlPoints } from '@fireweaveai/server-sdk/start';

start({ controlPoints: defineControlPoints({ 'new-checkout': { local: true } }) });
await fw.controlPoints.getBooleanValue('new-checkout', false, { targetingKey: user.id });
```

</CodeGroup>

Details: [Start profile](/sdks/start-profile).

## Removed

| Removed | Instead |
| --- | --- |
| OpenFeature providers | Retired. Read through the SDK's own `controlPoints` methods. |
| `client.flags` alias | `client.controlPoints` |

<Note>
Fireweave still answers 2.x SDKs, so you can upgrade one app at a time.
</Note>
