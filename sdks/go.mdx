title: "Go"

---

The Go SDK is the module `github.com/FireWeave-HQ/fireweave-sdk/sdks/go/v3`. Its `fw` package is the [start profile](/sdks/start-profile): one call in `main`, then reads from anywhere.

<Steps>
  <Step title="Install">
    ```bash
    go get github.com/FireWeave-HQ/fireweave-sdk/sdks/go/v3@v3.1.0
    ```
    The `/v3` suffix is required in `go get` and in every import path.
  </Step>
  <Step title="Declare your control points">
    ```go internal/fireweave/control_points.go
    package fireweave

    import "github.com/FireWeave-HQ/fireweave-sdk/sdks/go/v3/fw"

    // Every control point the app reads, with the value served in local mode.
    var ControlPoints = fw.DefineControlPoints(fw.LocalControlPoints{
    	"new-checkout": {Local: true, Description: "new checkout flow"},
    })
    ```
  </Step>
  <Step title="Start once in main">
    ```go main.go
    // appfw is your internal/fireweave package
    if err := fw.Start(fw.Options{ControlPoints: appfw.ControlPoints}); err != nil {
    	log.Fatal(err)
    }
    defer fw.Shutdown(context.Background())
    ```
  </Step>
  <Step title="Read a control point">
    ```go
    // @fireweave-controlpoint new-checkout
    if fw.ControlPoints().GetBooleanValue("new-checkout", false, fw.For(user.ID)) {
    	// new path
    }
    ```
    Reads never panic or fail. If start failed, they return your default.
  </Step>
</Steps>

## Configuration

| Variable | Value |
| --- | --- |
| `FIREWEAVE_KEY` | Your project key (`project-api-key_…`). Set it in every deployed environment. |
| `FIREWEAVE_ENV`, then `APP_ENV` | `development`, `dev`, `local` or `test` with no key runs local. |
| `FIREWEAVE_URL` | Optional. Overrides the default endpoint. |

With no key outside a development environment, `fw.Start` returns a configuration error naming `FIREWEAVE_KEY`. A deploy that forgot its key fails at start instead of quietly serving defaults.

## Identify users

At sign-in, register the facts your targeting matches on:

```go
err := fw.Identify(ctx, user.ID, map[string]any{"plan": user.Plan})
```

Pass attributes for one read with `fw.For(user.ID, map[string]any{"plan": user.Plan})`.

## Status

`fw.Status()` reports the mode and why, the channel, endpoint, key source and any start error. It never contains the key.

<Note>
  `fw.Client()` returns the one `*fireweave.Client` for the process, for dependency injection. To configure the client yourself with no environment reads, use `fireweave.Init` from the `fireweave` package.
</Note>
