FireWeave asks for read-only access and checks the credentials before saving.

## Add an account

Go to **Settings › Integrations**, pick the tool and press **Add account**. Adding an account needs an Owner or Admin, or a role with **Manage integrations**. You can also add one on the **Tools** step of [Create a project](/connect/create-project).

## Choose accounts per environment

Open your project's **Environments** page and edit an environment. Under **Observability**, pick the account for each signal:

| Signal | Used for |
| --- | --- |
| **Metrics** | The default source. A metric that names no source reads from this account. |
| **Logs** | Log queries for that environment. |
| **Traces** | Trace queries for that environment. |

### More metrics sources

Need metrics from a second account or tool? Use **Add a metrics source**. Each account can be added once. You can add one while rollouts are live, but you can't remove one a live rollout reads from.

<Tip>Automatic ramps need an observability account in at least one environment. See [Strategies and checks](/ship/strategies-and-checks).</Tip>
