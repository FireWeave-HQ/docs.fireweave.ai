## For coding agents

If you are a coding agent working in a repository that uses FireWeave, read these two pages first:

- [Set up FireWeave](/setup): how a repository gets set up, in the cloud or locally.
- [Build features with FireWeave](/agents/building-features): how to wrap a change behind a control point.

<Note>
Agents never register, start, ramp or promote rollouts. A person presses **Start rollout** in the [web app](https://app.fireweave.ai).
</Note>
